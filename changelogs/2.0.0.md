# Commonwealth Online 2.0.0

Commonwealth Online 2.0.0 is the biggest update since launch, and it changes what Commonwealth Online is. The networking core has been rebuilt from the ground up as a native C++ server on Valve's GameNetworkingSockets, sessions now hold **16 players**, and you can host a world from your own PC and invite friends through **Steam** with no VPS, no port forwarding, and no IP addresses to share.

The world is shared far more deeply, too. NPCs have shared health and fight players. Loot, inventory, trading, workshops, doors, locks, and equipment all stay in sync. There is a global chat, player factions, exact-modpack matching, password-protected servers, verified saves, and a long list of stability, security, and performance work underneath.

Commonwealth Online 2.0.0 supports Fallout 4 **1.10.163** (Old-Gen), **1.10.984** (Next-Gen), and **1.11.240** (current Anniversary Edition).

## Highlights

- Host a world from your own PC and share it with Steam friends. No VPS, no port forwarding, no public IP.
- A brand-new native C++ server, faster and lighter, with a Windows host app and a Linux hosting guide.
- 16 players per session.
- Shared NPCs: shared health, NPCs that fight players, and shared NPC loot.
- Inventory, container, and trade sync, plus shared equipment, drops, weapon mods, and workshop building.
- Shared doors and locks.
- Global chat and player factions, with their own in-game windows.
- Server passwords, exact-modpack matching, and verified multiplayer saves.
- Full gamepad support through the PrismaUI V12 controller stack.
- A security, validation, and stability pass across the whole stack.

## Host with Steam, no server needed

- Added Steam friends hosting. Start a world from your own PC and let your Steam friends join.
- No VPS, no router port forwarding, and no public IP address are needed.
- Added the new **Friends (Steam)** tab to the Multiplayer screen, with a plain-language guide that explains what hosting is and how it works.
- The host picks a world name, optional password, and player limit, then shares a **Friend Code**.
- Friends enter the Friend Code to join. Friend Codes are checked as you type, so typos are caught before you try to connect.
- Only your Steam friends can connect to your world, and the host can hold up to 16 players.
- Traffic travels over Steam's relay network, so connections work through most home routers.
- Steam hosting uses your existing Fallout 4 Steam session. There is nothing extra to install or sign in to.
- Hosting is designed to work on Old-Gen, Next-Gen, and Anniversary Edition. The mod checks what your game's Steam components provide and tells you plainly if hosting is not available instead of failing silently.
- Dedicated servers, LAN play, and Direct Connect are all still available for communities that want a 24/7 world.

## A new native server

- Rebuilt the multiplayer server as a native C++ application on Valve GameNetworkingSockets. The managed server has been retired.
- Faster, lighter, and simpler to run than the previous server stack.
- The server and the game now share a common core library, so rules and validation behave identically on both sides.
- Added an Ubuntu systemd hosting guide for running a server on a VPS or a home Linux machine.
- Fixed ports and defaults are documented: gameplay on UDP 7777, LAN discovery on UDP 7778, and a localhost-only admin channel.
- The server writes player state durably without blocking the game tick, so saving never causes lag spikes.
- Added a bandwidth regression guard so snapshot sizes stay lean as new features are added.
- Persistence costs were measured and tuned for large, long-running worlds.
- Session capacity is raised to 16 players.
- Server-side join workers are now owned and cleaned up correctly when a join fails.

## Host window

- The graphical Host window now runs on the native server.
- Start and stop the server, edit its configuration, and watch its log.
- Kick and ban players from the window.
- Added an optional **server password** field.
- Choose whether your world is listed publicly or kept private.

## Server browser and directory

- **Browse** now reads the live server directory.
- A clear notice appears if the directory cannot be reached, instead of an empty list.
- The curated server list is also published at `/servers/server.json` for community sites and tools.
- Public listings are validated by the directory before they appear.
- Added a **Share Log** button that redacts private details, so you can send a bug report without leaking personal data.
- Modpack mismatches now tell you exactly which mods differ between you and the server.
- Added a password prompt for protected servers, with retry handling.
- Join progress, Cancel Join, and Retry Join continue to work across all connection types.

## Controller and menu

- Ported the complete PrismaUI V12 controller stack.
- Navigate tabs, lists, filters, Direct Connect fields, and the Friends (Steam) tab with a gamepad.
- The on-screen keyboard lets controller users type addresses, Friend Codes, passwords, and filters.
- Controller prompts match the control you have focused.
- Added live settings refresh behind safe gates: HUD opacity, controller rumble, difficulty, and audio master volume.
- Added a compass and crosshair route for live settings that need no game call.
- Resolution and window mode are now launcher-only settings, so they cannot get out of step with the game.

## Shared NPCs and combat

- NPCs now have **shared health**. Damage one player deals to an NPC is seen by every player.
- **NPCs fight players.** Hostile NPCs attack, and their damage reaches players in sync across the session.
- **Shared NPC loot.** When a player loots an NPC, the contents are consistent for everyone, and what one player takes is gone for the rest.
- NPC synchronization was split into clean modules and checked against the engine so it is correct on every supported runtime.
- Added a projectile launch hook for exact ranged hit attribution, so the right player gets credit for the shot.
- Fixed player-versus-player damage so damage reduces health instead of healing it.
- Fixed hit events so they fall back to the right target and attacker when the engine does not provide one.
- Fixed the midnight clock wrap in combat timing.
- Remote player actors are protected from engine kill and death paths that could crash the game.

## Inventory, trading, and items

- Inventory is now synchronized between your game and the server. The game remains the source of truth for what you own.
- Added container and trade inventory sync with server-side validation of every change.
- Added a container-changed hub that watches inventory changes as they happen in the game.
- Added a drop mirror table, so dropped items show up for other players and stay consistent.
- Equipped gear and dropped items are shared between players.
- Added **weapon mod sync**, so remote players show the weapon mods you have built.
- Weapon mod sync is enabled on Old-Gen as well.

## Workshop and world objects

- Added server-authoritative **workshop transactions**. Placing and scrapping objects in a settlement is validated by the server.
- Workshop placement, move, and scrap actions are observed on the client and reported once.
- Doors and locks are shared. When one player opens, closes, locks, or unlocks a door, everyone sees it.
- Added object-state tracking for doors, activators, and locks.

## Chat

- Added **global text chat** to the Multiplayer screen with a live chat tab and a passive chat feed.
- Chat is carried by the server, so everyone on the server sees the same conversation.

## Player factions

- Added **player factions**. Create a faction or join one with your friends.
- Added a Factions window in the in-game Multiplayer UI.
- Faction membership and changes are validated by the server.

## Saves, profiles, and reconnecting

- Multiplayer saves are now **attested**, so the game prefers a verified save when you rejoin a server.
- Fixed first-join profile binding so your character always binds to the right save.
- Fixed save-and-quit so the game finishes writing your exit save before disconnecting.
- Fixed the save lineage so it settles on the save file itself instead of on timing.
- Fixed loading work that could run at the wrong time after a save loaded.
- Improved reconnect handling and missing-save recovery.
- Resume tokens now report a useful error code if Windows data protection fails.

## Modpacks

- Servers can now require an **exact modpack**. Players with different mods are told what to change before they join.
- The modpack is described by a manifest that the server and client both check.
- Added a launcher **pre-flight check** that verifies your installation before you play, with a read-only command-line mode for troubleshooting.

## Passwords, identity, and admission

- Added optional **server passwords** across the server, the Host window, the join flow, and the in-game prompt.
- Added protocol V2 identity: each client presents a profile identity, game version, runtime version, and mod manifest fingerprint when it connects.
- The server checks identity at the door, before gameplay traffic is accepted.
- Added session resume tokens for quick reconnects.

## Player synchronization

- Remote players now move more smoothly, with improved interpolation of other players' movement.
- Proxy actors derive movement direction from velocity and heading, and use consistent turn units.
- Remote actions are retried briefly and compared in a wrap-safe way, so animations no longer drop when the counter rolls over.
- Pinned proxy sneaking to a single reliable path.
- Gated proxy attack animation replay so it cannot fire at the wrong time.
- Animation graph calls now stay off locks to avoid stalls.

## Security and validation

- Added fuzz testing for the validators in every game area, which found and fixed six validator issues before release.
- Locked the proxy form lookup used by hit event sinks.
- Failed closed on unverified runtimes in proxy path predicates, so an unknown game version disables a feature instead of risking a crash.
- Scoped the networking remote-address lookup to the server bridge's own connections.
- Applied every item from the release audit, including dead code removal and splitting oversized files.
- Added an **opt-in mutation ring and first-fault dump** to capture useful crash data for troubleshooting.
- Release builds keep new features gated and verified.

## Platform support

- Supports Old-Gen (1.10.163), Next-Gen (1.10.984), and Anniversary Edition (1.11.240).
- Anniversary Edition support targets the current 1.11.240 build.
- Commonwealth Online does **not** redistribute PrismaUI_F4. It remains a separate dependency.
- Commonwealth Online ships with its own PrismaUI views for the browser, chat, and factions.

## Under the hood

- Replaced the old networking layer with GameNetworkingSockets direct transport, built in clean stages.
- Added a central replication runtime that owns the session and a reliable outbound mailbox.
- Split the largest source files into focused units: the client entry point, local player state, movement, runtime publishing, and the proxy actor controller (now 17 modules).
- Added a central test-features switch so unfinished features can be enabled in development and test builds while staying off in release.
- Removed unused scaffolding and dead dependencies.
- Consolidated and refreshed the documentation.

## Build, CI, and releases

- Added Windows compile lanes and Python toolchain provisioning for continuous integration.
- Faster CI with host caches for GameNetworkingSockets and protobuf, compiler caching, and fewer redundant runs.
- Release configuration builds are checked on every change.
- Added release acceptance checks for the Prisma controller contract, the dev build contract, and launch hook contracts.
- Release assets are published through automated release steps.
- Packaged client and server downloads keep a clean layout.

## What 2.0.0 changes for players

A player can now:

1. Install Commonwealth Online with PrismaUI_F4 as a separate dependency.
2. Open Multiplayer and choose **Friends (Steam)** to host a world, or **Browse** to find a public server.
3. Share a Friend Code with Steam friends so they can join without any network setup.
4. Play with up to 16 players in one shared Commonwealth.
5. Fight alongside others against shared NPCs, loot them together, and trade items.
6. Build in settlements together, and see doors and locks change for everyone.
7. Chat with everyone on the server and join a faction.
8. Rejoin the same character and save on any server, with verified saves.
9. Play on password-protected servers and exact-modpack servers.
10. Do all of it with a controller.
