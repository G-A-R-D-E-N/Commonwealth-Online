# Commonwealth Online 2.0.0

Commonwealth Online 2.0.0 is the biggest update since launch. The networking core has been rebuilt as a native C++ server on Valve's GameNetworkingSockets, and you can now host a world from your own PC and invite friends through Steam, with no VPS, no port forwarding, and no IP addresses to share. The world is shared much more deeply too: NPCs, loot, inventory, doors, workshops, chat, and player factions all work between players.

Commonwealth Online 2.0.0 supports Fallout 4 1.10.163 (Old-Gen), 1.10.984 (Next-Gen), and 1.11.240 (current Anniversary Edition). Up to 16 players can play together.

## Host with Steam, no server needed

- Added Steam friends hosting: start a world from your own PC and let your Steam friends join.
- No VPS, no router port forwarding, and no public IP address are needed.
- Added the new Friends (Steam) tab to the Multiplayer screen, with a plain-language guide to hosting and joining.
- The host sets a world name, optional password, and player limit, then shares a Friend Code.
- Friends enter the Friend Code to join. Only your Steam friends can connect to your world.
- Traffic travels over Steam's relay network, so connections work through most home routers.
- Hosting works on Old-Gen, Next-Gen, and Anniversary Edition.
- Dedicated servers, LAN play, and Direct Connect remain available for communities that want a 24/7 world.

## New native server

- Rebuilt the multiplayer server as a native C++ application on Valve GameNetworkingSockets.
- Faster, lighter, and easier to run than the previous server stack.
- Added a Windows host application and an Ubuntu systemd hosting guide for running a server on a VPS or home Linux box.
- Added optional server passwords, set from the Host window or the server configuration.
- Added a password prompt in the game for protected servers.
- Added a bandwidth regression guard so snapshot sizes stay lean as features are added.
- Server and client now share a common core library, so game rules behave the same on both sides.
- The curated server list is also served at `/servers/server.json` for community sites and tools.

## Server browser and controller

- Browse now reads the live server directory, and shows a clear notice when the directory is unreachable.
- Ported the complete PrismaUI V12 controller stack. Navigate tabs, lists, filters, and Direct Connect with a gamepad, including the on-screen keyboard.
- Added a Share Log button that redacts private details, so you can send a bug report without leaking personal data.
- Modpack mismatches now tell you exactly which mods differ between you and the server.

## Shared NPCs

- NPCs now have shared health. Damage one player deals to an NPC is seen by everyone.
- NPCs fight players. Hostile NPCs attack and are fought by whoever they target, in sync across the session.
- Shared NPC loot: when a player loots an NPC, the container contents stay consistent for everyone, and what one player takes is gone for the rest.
- Remote players now move more smoothly, with improved interpolation of other players' movement.
- Remote player actors are protected against crashes from engine kill and death paths.

## Inventory, trading, and items

- Inventory is now synchronized between the game and the server, and the game remains the source of truth for what you own.
- Added container and trade inventory sync, with the server validating every change.
- Equipped gear and dropped items are shared between players.
- Added weapon modification sync, so remote players show the weapon mods you build.
- Added shared workshop transactions: placing and scrapping objects in a settlement is validated by the server.
- Doors and locks are now shared. When one player opens, closes, locks, or unlocks a door, everyone sees it.

## Chat

- Added global text chat to the Multiplayer screen with a live chat tab.
- Chat is carried by the server, so everyone on the server sees the same conversation.

## Player factions

- Added player factions: create or join a faction with your friends.
- Added a Factions window in the in-game Multiplayer UI.
- Faction membership is validated by the server.

## Saves, profiles, and reconnecting

- Multiplayer saves are now attested, so the game prefers a verified save when you rejoin a server.
- Fixed first-join profile binding so your character always binds to the correct save.
- Fixed save-and-quit so the game finishes writing the exit save before disconnecting.
- Fixed the save lineage settling on the save file itself rather than on timing.
- Fixed loading work that ran at the wrong time after a save load.

## Modpack compatibility

- Servers can now require an exact modpack. Players with different mods are told what to change before joining.
- Added a launcher pre-flight check that verifies your installation before you play, with a read-only command-line mode for troubleshooting.

## Stability and fixes

- Fixed player-versus-player damage so damage reduces health instead of healing it.
- Fixed proxy sneaking, proxy attack animation replay, and proxy direction handling.
- Fixed a race in remote-actor lookups used by hit tracking.
- Fixed clock wrap at midnight and target fallback in hit events.
- Fixed weapon mod sync being unavailable on Old-Gen.
- Fixed resume tokens reporting no useful error when Windows data protection failed.
- Release builds now run through a full release-configuration CI lane.

## Platform support

- Old-Gen (1.10.163), Next-Gen (1.10.984), and current Anniversary Edition (1.11.240) are supported.
- Anniversary Edition support targets the current 1.11.240 build.
- Commonwealth Online does **not** redistribute PrismaUI_F4. It remains a separate dependency.

## What 2.0.0 changes for players

A player can now:

1. Install Commonwealth Online with PrismaUI_F4 as a separate dependency.
2. Open Multiplayer and choose Friends (Steam) to host a world, or Browse to find a public server.
3. Share a Friend Code with Steam friends so they can join without any network setup.
4. Fight, loot, trade, build, and chat with up to 16 players in a shared Commonwealth.
5. Form a faction with friends.
6. Reconnect to the same character and save on any server.
