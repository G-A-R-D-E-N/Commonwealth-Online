# Commonwealth Online 1.0.6

Version 1.0.6 brings a large part of the public multiplayer foundation together into a more complete build. Hosting is easier, public servers can be discovered, joining is more reliable, character setup is safer, reconnecting is improved, the UI has received major work, and the networking and save systems have been hardened.

## UI and server browser

- Reworked the Multiplayer server browser.
- Added public Browse listings, LAN discovery, and Direct Connect.
- Improved keyboard, controller, text-field, and keyboard-focus navigation.
- Fixed shortcuts activating while typing and duplicate Direct Connect actions.
- Added join progress feedback, Cancel Join, and Retry Join.
- Improved connection status, server details, and recent-server information.
- Refreshes no longer freeze the UI or leave stale results after reopening Multiplayer.
- Fixed failed refreshes leaving Browse stuck loading.

## Character creation and first join

- Added first-time server onboarding through COVault109.
- Added LooksMenu and SPECIAL tracking to the multiplayer join flow.
- Improved the third-person character creation camera, face-edit positioning, and zoom.
- Restored player position, camera state, and FOV after customization.
- Added fallback and timeout handling when character creation does not open correctly.
- Added cleanup when first-time onboarding fails.
- First-time joins now wait for a stable gameplay area.
- Setup saves from COVault109 can no longer become permanent multiplayer saves.

## Player sync

- Added remote player proxy actors with position, rotation, movement, sprint, sneak, crouch, jump, and weapon-drawn state synchronization.
- Added locomotion animation, appearance, body morph, hair color, head-part, face morph, tint, complexion, clothing, armor, hats, eyewear, and partial weapon visual synchronization.
- Improved cell-change handling and cleanup when remote players disconnect.

## World sync

- Added shared weather, shared time, and server-controlled world state.
- Fixed weather being sent to the wrong player after host changes.
- Fixed restart-related player and host assignment issues.
- Fixed incorrect time application and reduced unnecessary time updates.
- Improved world-state ownership and reassignment.

## Joining, saves, and reconnecting

- Added server-specific character and save profiles.
- First-time joins remain pending until the multiplayer save is actually created.
- Improved reconnect, missing-save, deleted-save, exit-save, and rotating exit-save recovery.
- Equivalent server addresses such as `localhost` and `127.0.0.1` resolve to the same profile.
- COVault109 setup saves are rejected during profile binding.
- Added profile backups, recovery, and safer profile writes.
- Failed writes roll back instead of leaving broken profile data.
- Disconnecting during onboarding now cleans up correctly.
- Old join attempts cannot interfere with newer joins.
- Current joins recover cleanly when the connection disappears during startup.

## Server hosting

- Added a public server directory and public server registration.
- Added automatic heartbeat registration and automatic removal of offline servers from Browse.
- Added LAN discovery, direct IP hosting, server names, descriptions, and player limits.
- Public address detection is handled by the directory.
- Hosts no longer need to manually advertise their public IP.

> A simplified end-user server host is also being worked on. The goal is a normal Host Server window where players can enter a server name, choose LAN or Public hosting, set a player limit, and click Start Server.

## Bug fixes and stability

- Fixed joins, onboarding, character creation, gameplay transition waits, profile binding, and browser refreshes becoming stuck.
- Fixed stale callbacks and directory results affecting newer connections.
- Fixed missing player state, missing saves, setup-save binding, exit-save rotation, and damaged profile recovery.
- Fixed directory socket setup and receive-timeout failures being ignored.
- Fixed partial socket sends and bounded oversized network frames.
- Added packet-rate, bandwidth, remote-player-state, and diagnostic-state protections.
- Removed unsafe network-triggered weather console execution.
- Improved time validation, weather validation, disconnect cleanup, and directory failure handling.

## Networking and security

- Added maximum incoming packet sizes and protection against malformed and incomplete packets.
- Added per-connection packet limits, bandwidth limits, and protection against sustained abusive traffic.
- Public directory listings use the IP address observed by the directory.
- Servers cannot redirect players to arbitrary hostnames through directory registration.
- Private and special-use addresses are blocked from public Browse listings.
- Directory capacity, connection counts, and request rates are bounded.
- Invalid directory configuration now fails safely.

## Build and release improvements

- Added packaged client and server downloads.
- Improved client and server release layouts.
- Fixed PrismaUI builds reporting success when the actual build failed.
- Fixed stale PrismaUI DLL reuse and require a fresh PrismaUI DLL for a successful build.
- Fixed broken Ultralight SDK links reporting success.
- Added an Ultralight copy fallback when junctions are unavailable.
- Added pinned third-party build revisions and improved ZIP compatibility.
- Expanded automated testing across the client, server, browser, saves, networking, and directory systems.

## Still in development

- Combat and damage syncing.
- Inventory and loot.
- Quest synchronization.
- Settlement synchronization.
- NPC and broader world synchronization.
- Companions, dialogue, VATS, full weapon behavior, and power armor.

## What comes next

Version 1.0.6 is the public-facing release while the next major Commonwealth Online update is developed. The current public version continues using the Python relay while the next-generation dedicated server is rebuilt in C++ around better performance, scalability, reliability, and a stronger multiplayer foundation.

Version 1.0.6 improves the Commonwealth Online you can play today. The next major update rebuilds the foundation underneath it.
