        CHECK MY SETUP

        Start here. It checks the usual Commonwealth Online problems: the game left open, Steam, the game port, leftover hosting files, the server files, and the mods the game needs for your Fallout 4 version. It only reads; nothing is changed.

          END LEFTOVER SERVERS

          Use this when hosting says the running server did not answer the settings link in time and the game is closed. It ends the server programs the game started for hosting and left running.

          CLEAR HOSTING LINK FILES

          Use this after END LEFTOVER SERVERS if hosting still fails. It deletes the leftover link files that hosting keeps in AppData. Close the game first.

          REPAIR SERVER FILES

          Use this if the server files are missing or damaged. It puts the bundled server back into your Mod Organizer 2 setup and turns the mod on. Close Mod Organizer 2 first.

          RESET SAVED SERVER FOLDER

          Use this if the in-game server panel keeps opening a folder you no longer use. It forgets the server folder you picked there.

          CHECK SERVER FILES

          Use this to see every copy of the server program in your Mod Organizer 2 setup, with its size and date. It only reads; nothing is changed.
