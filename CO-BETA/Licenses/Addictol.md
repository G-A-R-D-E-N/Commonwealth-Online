# Addictol and Addictol Crash Logger Third-Party Notice

Commonwealth Online ships two unmodified, separately built Fallout 4 plugins from the Dear-Modding-FO4 project, each pinned as a git submodule:

- Addictol (https://github.com/Dear-Modding-FO4/Addictol), commit b09e5000ca76fc2a1632a4bbfd973a81f18b9cd5, at `ThirdParty/Addictol`. Engine bug fixes and performance patches for Fallout 4 OG 1.10.163, NG 1.10.984 and AE 1.11.240. It consolidates earlier community work, including Buffout 4, X-Cell, Mentats and Escape Freeze Fix, as its own README credits.
- Addictol Crash Logger (https://github.com/Dear-Modding-FO4/AddictolCrashLogger), commit b5aa2c8c0b11c2b690afc760a4494a143dbe9dec, at `ThirdParty/AddictolCrashLogger`. Crash and thread reports based on Buffout 4 NG's Crash Logger with CrashLoggerSSE enhancements.

The complete `LICENSE` and `EXCEPTIONS` texts are in each submodule directory and are copied next to the built plugins in every Commonwealth Online release package, together with the instructions for obtaining the corresponding source (the two repository URLs and commits above).

Commonwealth Online does not modify the code of either project. Their dependencies keep their own licenses, which are listed in each project's source tree.
