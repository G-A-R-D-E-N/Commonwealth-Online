# Profile icon attribution

The account profile selector uses six Fallout 4 perk images:

- Armorer
- Hacker
- Rifleman
- Medic
- Scrapper
- Cap Collector

Source repository:

- https://github.com/CircuitBread0111/Fallout_Perk_Planner
- pinned source commit: `918547cc872c3288122f9d15ed0416cf33aa8bbf`
- source files: `perk_images/*.png`

The site loads the images from immutable jsDelivr URLs pinned to that commit. The image files are not copied into this repository and users cannot upload replacement profile images.
